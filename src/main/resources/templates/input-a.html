A 股数据输入

三种方式任选其一：自动抓取（推荐）→ 理杏仁 CSV → 手动输入

自动抓取（新浪财报 + 东财行情）
6 位数字，支持 sh/sz 前缀与全角字符
抓取内容：10 年经营现金流 / 资本开支 / 营收 / EBIT / 税率数据（新浪）， 当前股价 / 总股本 / 有息负债 / 少数股东权益（东财）。Beta 将在参数页自动计算。
理杏仁 CSV / 标准模板导入

可下载标准模板填写，或直接上传理杏仁导出的 CSV（自动识别中文科目列）。 历史数据来自 CSV；以下快照字段（股价/股本/负债）需手动补充。

短借+长借+应付债券+一年内到期+租赁负债
下载标准 CSV 模板
手动输入历史财务（A 股）

至少 3 年，建议 5-10 年；金额单位：元。营收/EBIT/税前利润/所得税可选填（用于增长参考与税率）。
